# Code of conduct

KeepKeys contributors must be respectful, technically honest, and careful with security-sensitive information.

- Critique code and claims, not people.
- Do not pressure anyone to disclose credentials, private reports, personal data, or account access.
- Do not publish an uncoordinated exploit or test against systems you do not own.
- Do not use “secure,” “safe,” or “encrypted” as an absolute claim; name the control and its limit.
- Report harassment or private security concerns through the private channel in [SECURITY.md](SECURITY.md).

Maintainers may remove contributions or participation that violate these boundaries.
